# Manhattan dialogue

This folder contains one Markdown script for each currently scripted Manhattan, neighborhood, or landmark camera view.

## Subfolders

This folder has no direct subfolders.

## Files

- `manhattan.md` contains the Manhattan arrival and neighborhood-choice narration.
- `washington-square.md` contains the Washington Square campus narration.
- `lipton-hall.md` contains the Lipton Hall residence narration.
- `bobst-library.md` contains the Bobst Library campus-life and robotics-project narration.
- `stern-school-of-business.md` contains the Stern clubs, Machine Learning Team, and Infrastructure Masons project narration.
- `courant-institute.md` contains the Courant double-major and Tech@NYU leadership narration.
