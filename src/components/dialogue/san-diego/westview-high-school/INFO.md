# Westview High School dialogue

This folder owns the Markdown dialogue for the Westview High School camera view. `../../index.ts` exports the script to the shared dialogue renderer.

## Subfolders

This folder has no direct subfolders.

## Files

- `westview-high-school.md` contains the school and club narrative, including the East Asian Student Union link.
- `INFO.md` documents this folder and its script.
