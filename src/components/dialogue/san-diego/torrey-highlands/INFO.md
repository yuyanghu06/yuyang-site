# Torrey Highlands dialogue

This folder owns the Markdown dialogue for the Torrey Highlands camera view. `../../index.ts` exports the script to the shared dialogue renderer.

## Subfolders

This folder has no direct subfolders.

## Files

- `torrey-highlands.md` contains the neighborhood welcome and childhood/school context for the Torrey Highlands district camera.
- `INFO.md` documents this folder and its script.
