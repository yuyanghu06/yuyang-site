# Torrey Pines dialogue

This folder owns the Markdown dialogue for the Torrey Pines camera view. `../../index.ts` exports the script to the shared dialogue renderer.

## Subfolders

This folder has no direct subfolders.

## Files

- `torrey-pines.md` contains the coastal beach, bluffs and lagoon narration for the Torrey Pines district camera.
- `INFO.md` documents this folder and its script.
