# San Diego dialogue

This folder contains intentionally provisional Markdown for the Torrey Highlands overview and its two landmark camera stops. The shared caption renderer, audio, Next/Back controls, and inline Reply composer match the New York experience. No personal memories are asserted by these placeholders.

## Direct subfolders

There are no direct subfolders.

## Direct files

- `INFO.md` documents this folder.
- `san-diego.md` introduces the Camino del Sur / SR-56 overview and starts the route to Westview.
- `westview-high-school.md` supplies the Westview camera placeholder and continues toward the plaza.
- `torrey-highlands-plaza.md` supplies the plaza camera placeholder mentioning Chef Zhu's.
- `tour-complete.md` introduces the overview, New York, and globe return choices after the plaza.
