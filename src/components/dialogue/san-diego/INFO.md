# San Diego dialogue

This folder supplies the regional destination choices and the Torrey Highlands, coastal, and canyon tour captions. The shared caption renderer, audio, Next/Back controls, and inline Reply composer match the New York experience. Geographic captions describe visible scenery; existing school/plaza stories remain provisional and assert no personal memories. The waterfall is part of the Park Village base view and never a separate tour destination.

There are no direct subfolders.

## Direct files

- `INFO.md` documents this folder.
- `san-diego.md` introduces the wider region and the three neighborhood choices.
- `torrey-highlands.md` introduces the preserved Camino del Sur / SR-56 view before Westview.
- `westview-high-school.md` supplies the Westview camera placeholder and continues toward the plaza.
- `torrey-highlands-plaza.md` supplies the plaza camera placeholder mentioning Chef Zhu's.
- `torrey-pines.md` describes the coastal beach, bluffs, and lagoon before the canyon visit.
- `park-village.md` describes the neighborhood/canyon view and its visible waterfall feature.
- `tour-complete.md` introduces the overview, New York, and globe return choices after Park Village.
