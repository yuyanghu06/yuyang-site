# Park Village dialogue

This folder owns the Markdown dialogue for the Park Village camera view. `../../index.ts` exports the script to the shared dialogue renderer.

## Subfolders

This folder has no direct subfolders.

## Files

- `park-village.md` contains the canyon and visible waterfall narration for the Park Village district camera; the waterfall has no separate tour destination.
- `INFO.md` documents this folder and its script.
