# Deer Canyon Elementary School dialogue

This folder owns the Markdown dialogue for the Deer Canyon Elementary School camera view. `../../index.ts` exports the script to the shared dialogue renderer.

## Subfolders

This folder has no direct subfolders.

## Files

- `deer-canyon-elementary-school.md` contains the manually selectable elementary-school camera narration.
- `INFO.md` documents this folder and its script.
