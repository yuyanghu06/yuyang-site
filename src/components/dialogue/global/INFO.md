# Global dialogue

This folder contains dialogue for the overall experience rather than a geographic camera view.

## Subfolders

This folder has no direct subfolders.

## Files

- `intro.md` contains the brief conversational tour invitation and uses the `{{age}}` placeholder for the birthday-derived runtime age.
- `city-choice.md` contains “Where should we go first?” for the globe's New York / San Diego city choice after accepting the invitation.
- `INFO.md` documents this folder and its authored scripts.
