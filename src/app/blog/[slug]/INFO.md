# Blog article route

This dynamic App Router segment statically generates one crawlable page for every record in the parent folder's `posts.ts` file. Unknown slugs are disabled and return not found behavior.

## Direct subfolders

This folder has no direct subfolders.

## Direct files

- `INFO.md` documents this folder.
- `page.tsx` renders an article, emits per-post metadata and Article structured data, and links readers to other posts and the main experience.
