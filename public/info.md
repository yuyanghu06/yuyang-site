# Public runtime assets

Files here are served directly by Next.js. Prefer changing an authoritative source or generator and regenerating its output instead of hand-editing exported artifacts.

## Direct subfolders

- `animations/` is the permanent location for exported animation GLBs.
- `audio/` contains short browser-served sound effects for streamed guide feedback.
- `data/` contains browser-served geographic and runtime datasets.
- `models/` contains web-ready 3D scene and character models plus reusable external motion sources.
- `style-references/` contains browser-accessible visual review and style-reference media.

## Direct files

- `.DS_Store` is macOS Finder metadata.
- `info.md` is this authoritative folder inventory.
