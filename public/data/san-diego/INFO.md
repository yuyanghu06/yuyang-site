# Torrey Highlands geographic data

Static, reproducible OpenStreetMap geography for the San Diego view, centered on the user's Camino del Sur / SR-56 screenshot and extending around the reviewed neighborhood. Its bounds span longitude −117.167 to −117.13425 and latitude 32.948 to 32.9755, increasing width by 31% and height by 37.5% with small north/west allowances for diagonal overview rotation. All local coordinates are meters, east +X and north −Z, relative to the unchanged longitude −117.1518, latitude 32.9606 origin. The overview camera remains unchanged.

There are no direct subfolders.

- `source.osm.json` is the compact OpenStreetMap source export with original feature IDs, tagged footprints, roads, landcover, source trees, and Chef Zhu's mapped restaurant point. The expansion retains all 3,951 original October 11 records in their original order and appends 2,287 new IDs from four October 13 map API exports; original records win where IDs overlap. `provenance` distinguishes the retained snapshot from the expanded acquisition, while `sourceExports` records each request URL, bounds, and retrieval time. It is licensed under ODbL 1.0, with attribution to OpenStreetMap contributors.
- `manifest.json` records geographic bounds, projection, source timestamp, Map3D commit, output hash, counts, assumptions, camera framing (overview zoom 0.5 and a 240-meter northward target shift to include Westview, the plaza, and Mesa Verde), merged landmark source IDs, the sage/cream/terracotta palette, all four selectable landmarks’ school/plaza source IDs and merged bounds, authored Mesa Verde athletics-field/track dimensions and reference provenance, and the lossless position-compression contract that preserves surface separation. Its `schoolDetails` records artistic-detail provenance, a separate school palette, campus/building source associations, per-campus counts, windows, roof vents, entrance canopies, and every authored surface/shade footprint.
- `layout.json` retains projected building/road/tree layout and exclusion polygons, including the authored Mesa Verde sports field, for reproducibility and independent geometry-placement audits. Its `schoolDetails` mirrors the manifest campus records; new surface and entrance-canopy footprints also join `treeExclusions`. Full-footprint containment and edge-distance checks cover concave roofs, parcels, mapped buildings and roads, with tree canopy clearance checked independently.
- `MAP3D-LICENSE.txt` preserves the upstream Map3D MIT copyright and license notice.
- `INFO.md` is this folder guide.

Generate with `node scripts/map-data/build-san-diego.mjs`; add `--refresh` only to request a new OSM snapshot. The ignored checkout at `data/work/map3d/` is pinned to commit `2c5d732477ba7c55995572aae926bf80303c00b9`. The generator executes its `Space.tsx` building-extrusion implementation, using metric projection and documented height inputs. Terrain elevation, inferred heights, facade details, and supplemental planting are stylized assumptions; footprints and street layout are mapped data.

Cached source bounds must cover the requested geography; otherwise regeneration stops with an actionable `--refresh` instruction. Undersized legacy XML cannot seed an expanded model. Expanded outputs contain 4,343 buildings, 1,597 road/path features, and 138 landcover polygons; the original reviewed Westview/plaza geometry and camera definitions remain intact.
