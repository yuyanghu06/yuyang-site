# Visual references

Review renders, contact sheets, and visual-direction images live here. These are references rather than runtime UI unless code explicitly imports them.

When a Figma target is supplied, generated style-reference images must also be placed in that Figma file.

## Direct subfolders

This folder has no direct subfolders.

## Direct files

- `generated-crumpled-paper-texture.png` is the AI-generated seamless warm-white paper surface used as the repeating, scroll-bound texture behind every blog route.
- The remaining PNG files are globe and Manhattan visual-review renders used to compare camera framing, materials, geometry, and generated preview directions.
- `info.md` documents this folder.
