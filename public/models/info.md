# Runtime 3D models

Web-ready GLB assets live here. Authoring sources are generally under `assets/blender/`, while generated city tiles are under `washington-city/`.

The authoritative avatar web assets are `yuyang-avatar-idle-loop-v2.glb` and `yuyang-avatar-talking-loop-v2.glb`, both using the same 54-bone V2 skeleton. Landmark models exposed to interaction must contain merged base-plus-detail geometry.
