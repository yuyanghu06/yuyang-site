# Washington Square tree population

- Added deterministic Washington Square tree placement using the same seven-sided trunks, low-poly icosahedron crowns, and muted materials as the Courant garden.
- Targets up to 88 trees while rejecting positions near mapped paths, the fountain, the arch, and existing trees.
- Randomly but deterministically scales roughly 18% of trees to 1.45–2× height and gives the remainder subtle natural variation.
- Added tree footprints to pedestrian route obstacles so walkers do not clip through trunks.
- ESLint and the optimized production build pass. No commit or push was performed.
