# Avatar Emote Set

- Replaced the ten-emotion/lip-sync/video-API direction with a compact game-dialogue animation set.
- Required assets are neutral idle, full-screen wave hello, generic talking with sentence pauses, smiling/tapping, thumbs up, point to the avatar's right, sad, and thumbs down.
- Consolidated the duplicate thumbs-up request into one clip.
- All gesture/emotion clips are silent one-shots that automatically return to neutral.
- The LLM tool selects only a semantic emote. The client owns playback, transitions, and the automatic neutral return.
- The one talking clip is controlled by streamed-text lifecycle and may be accompanied by synthesized robot-like dialogue blips; it is generic rather than lip-synced.
- Every finished clip must be exported as a video for user review before site integration.
