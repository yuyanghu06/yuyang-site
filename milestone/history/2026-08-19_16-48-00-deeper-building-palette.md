# Deeper building palette

- Replaced the pale context-building colors with a deeper sun-faded Village palette: limestone, sandstone, dusty brick, terracotta, sage, cool stone, aged cream, and dark brown-gray.
- Increased roof lightness relative to walls so individual building masses read more clearly.
- Reduced ambient hemisphere fill, strengthened the directional sun, lowered exposure, and tightened soft shadows for greater face-to-face depth.
- Pushed fog farther from the foreground and darkened streets, sidewalks, and park paths to strengthen the scene hierarchy.
- `npm run lint` and `npm run build` both pass.
