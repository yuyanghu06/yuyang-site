# Clickable Bobst and Gould Plaza

- Added translucent white edge-only outlines to Bobst Library and Gould Plaza on initial load.
- Added raycast hover discovery with pointer cursor and a smoothly animated 2.6-unit lift.
- Clicking either landmark locks in a 5-unit lift and eases the orthographic camera toward that landmark at a fixed azimuth with a modest zoom.
- Disabled horizontal camera rotation after a landmark has been selected.
- `npm run lint` and `npm run build` pass.
