# Gray pigeon models

- Split the mixed flock into two visual models rather than relying on color alone.
- White birds retain the light, long-winged cartoon silhouette.
- Gray birds now use a pigeon-specific model with a chunkier body, raised round head, tan beak, shorter broad wings, and compact tail.
- All sixteen birds retain their existing independent flight loops and flap animation.
- `npm run lint` and `npm run build` both pass.
