# Expanded San Diego region

Implemented the broader San Diego overview between globe and Torrey Highlands, plus fixed Torrey Pines and Park Village district views. Added photo-inspired rocky Peñasquitos Waterfall scenery and a static label to the base Park Village view; no separate waterfall camera exists. Existing Torrey Highlands geometry, original data files, and landmark camera values remain unchanged.

The reproducible OSM expansion is generated by `npm run data:san-diego-region` from a compressed 145,582-record snapshot. The final GLB is 23,335,732 bytes, SHA256 `b6fec23dc079a942fd4a1e7d0ce84510f0b4b4781b6fb844f3288a1e21e14150`. Shared surface triangulation, semantic layer heights, exact shoreline clipping, and a solid-object shadow allowlist fix the visual artifacts found during browser review. Generator assumptions and attribution are recorded alongside the assets.

Navigation, guide choices, tour order, parent/Back routes, agent schema, responsive camera fitting, and city audio all recognize the new hierarchy. Loader failure/cancellation cleanup is atomic across the two SD models. Original landmarks retain merged selectable roots. Free-camera authoring stays disabled.

Validation: TypeScript, targeted ESLint, registry/tour parity, deterministic regeneration, hashes, whitespace, independent geometry/source/loading audits, 39 input/raycast cases, 256 navigation pairs, and 35 responsive framing cases pass. Browser review confirms clean regional, Torrey Pines and Park Village views, visible waterfall annotation, original Torrey Highlands/Westview framing, and phone viewport fitting. No browser application errors observed.

Remaining limits: physical multitouch, full audio listening, and low-end-device performance were not measured. Model complexity is about 1.96 million triangles; relief, planting, outer skirts, and waterfall scale are stylized. Existing personal-story placeholders remain. No build, commit, push, or deployment was performed for this task.
