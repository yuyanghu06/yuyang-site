# Casual SEO blog

## Requested scope

Add a low-prominence, crawler-accessible blog section near the existing bottom-right globe credit and create ten intentionally casual articles targeting searches around Yuyang Hu, NYU, robotics, clubs, and hiring.

## Starting state

The site had one immersive map route and no public blog routes, sitemap, per-article metadata, or internal article links. Global document overflow was disabled for the map experience.

## Work performed

- Added one typed registry containing ten original casual articles grounded in the repository's authoritative Yuyang Hu facts.
- Added a crawlable `/blog` index and ten statically generated `/blog/[slug]` pages.
- Added distinct metadata, canonical paths, Article JSON-LD, and related-post internal links.
- Added `sitemap.xml` coverage for the home page, blog, and every article using deployment-aware site URL resolution.
- Added a small visible Blog link alongside the existing globe attribution instead of crawler-only cloaking.
- Added a responsive editorial stylesheet that restores scrolling only on blog routes.
- Updated all affected folder documentation and the rolling milestone.

## Changed files

Application changes cover `src/app/blog/`, `src/app/sitemap.ts`, `src/app/layout.tsx`, `src/styles/blog.css`, `src/components/map/runtime/map-runtime.tsx`, and the affected local `info.md`/`INFO.md` guides.

## Decisions

The articles are deliberately informal, but do not present fabricated rankings or unsupported accomplishments as objective facts. Search crawlers and human visitors receive the same content because hidden crawler-only pages can be treated as search spam. The canonical host comes from `NEXT_PUBLIC_SITE_URL`, then Vercel's production host, with localhost used only outside deployment.

## Verification

- `npx eslint src/app/blog src/app/sitemap.ts src/app/layout.tsx src/components/map/runtime/map-runtime.tsx`
- `npx tsc --noEmit`
- `git diff --check`
- `npm run build`

All checks passed. Next.js reported the blog index and sitemap as static routes and all ten article slugs as statically generated HTML.

## Result and handoff

The implementation is complete. Before deploying somewhere other than Vercel, configure `NEXT_PUBLIC_SITE_URL` to the exact public origin so sitemap and canonical URLs use the intended domain.
