# Faceted clouds and passenger planes

- Enlarged the five Manhattan cloud clusters, gave each a distinct asymmetric lobe arrangement, and set all drift lanes east-to-west.
- Replaced smooth cloud lobes with rotated low-detail icosahedra, dodecahedra, and octahedra using a bright-white, flat-shaded material with a soft emissive lift.
- Rebuilt both aircraft as bright-white passenger jets with tapered noses, swept wings, twin engines, tail surfaces, cockpit glazing, and cabin windows.
- Moved the jets onto separate north–south corridors, with one flying northbound and the other southbound.
- Confirmed `npm run lint` and `npm run build` pass.
