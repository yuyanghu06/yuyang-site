# Folder INFO Documentation Policy

- Added a repository rule requiring every folder to contain a clear English `INFO.md`.
- Each `INFO.md` must explain its folder's purpose and describe every direct subfolder and direct file.
- The containing folder's `INFO.md` must be updated in the same change whenever a file is added, removed, renamed, or updated; parent documentation must also track direct-subfolder changes.
- Recorded the new policy in the authoritative current milestone.
