# Avatar scripts

Blender/Python authoring and retargeting scripts live here. New work must target the authoritative 54-bone V2 rig, which has three connected deform joints for each digit. The `create-yuyang-avatar-*-loop-v2.py` wrappers generate the neutral and talking library loops from the shared retargeter. `add-talking-face-to-loop-v2.py` binds and animates the approved cheek-free atlas on a curved, head-weighted face canvas for the combined review render.
