# Blender sources

This directory contains only the active editable Blender sources for the globe, custom buildings, and avatar.

The authoritative avatar source is `yuyang-avatar-talking-loop-face-v2.blend`, containing the 54-bone corrected talking loop and approved animated 2D face canvas. The authoritative globe source is `lowpoly-earth-watercolor.blend`. Unused avatar and globe Blender files are archived under ignored `data/raw/`, not kept here.

`nyu-custom-buildings.blend` and its Blender backup remain the active custom-landmark authoring source.

Landmark detail geometry must be baked or merged with its base building before it becomes selectable or animated.
