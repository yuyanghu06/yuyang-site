# Working data

Local source downloads and intermediate conversion data belong here. Large raw and temporary work products are intentionally excluded from version control.

Tracked runtime datasets belong in `public/data/`; repeatable transformations belong in `scripts/map-data/`.

## Direct subfolders

- `raw/` contains ignored source downloads and recoverable archives.
- `work/` contains ignored intermediate conversion and review artifacts.

## Direct files

- `INFO.md` documents this folder.
